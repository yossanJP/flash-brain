# FLASH BRAIN

FLASH BRAIN is a fast-paced cyber mental-math arcade game built for quick replayability, flashy presentation, and satisfying score-chasing.

Players watch chained numbers appear in sequence, calculate the total in their head, and quickly enter the answer on a keypad before time runs out.

---

## Overview

FLASH BRAIN mixes:
- **mental math**
- **arcade-style speed**
- **combo and fever systems**
- **premium event presentation**
- **cyber / neon / gold UI**

The goal is simple:
**solve as many flash-calculation problems as possible before the timer ends.**

---

## Core Features

### 1. Flash Mental Math
Numbers appear one by one in a chain, for example:

`120 → 350 → 80 → 240`

The player mentally adds them, then enters the final total.

---

### 2. Fast Arcade Flow
- quick question pacing
- fast keypad input
- combo-based score growth
- strong replay loop
- easy to understand, hard to master

---

### 3. Combo System
Correct answers build combo.

Higher combo means:
- stronger momentum
- better score growth
- higher tension
- more exciting visual feedback

---

### 4. FEVER
Success builds toward **FEVER**.

FEVER is a reward state that increases excitement and scoring potential, with stronger visual presentation and a more intense pace.

---

### 5. Premium FREEZE Event
A rare **FREEZE** event can trigger during a run.

This event is designed as a premium surprise moment, inspired by dramatic Japanese arcade / slot-style presentation:
- screen crack effect
- glitch / noise
- CRT-style shutdown
- blackout suspense
- special transition

---

### 6. OVERDRIVE ZONE
After FREEZE, the game can transition into **OVERDRIVE ZONE**.

OVERDRIVE ZONE gives the player:
- **+20 seconds**
- **2x score gains during the zone**

This is the highest-excitement state in the game.

---

## How to Play

1. Start the game
2. Watch the numbers appear in sequence
3. Mentally calculate the total
4. Enter the answer on the keypad
5. Press **ENT**
6. Keep answering correctly to build combo and trigger FEVER
7. Chase high scores and premium event runs

---

## Controls

### Desktop
- Number keys / keypad input
- **Enter** to submit
- **Backspace** to delete (if supported by current build)

### Mobile
- Tap the on-screen keypad
- Tap **ENT** to submit
- Tap **PASS** if needed

---

## Visual / Audio Direction

FLASH BRAIN is built around a distinct presentation style:

- **black background**
- **gold + blue neon accents**
- **futuristic calculator / console UI**
- **arcade jackpot energy**
- **high-impact transitions**
- **cyber sound design**
- **premium event feel**

The game is intentionally designed to feel more dramatic and luxurious than a typical brain-training game.
